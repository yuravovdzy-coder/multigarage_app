# Multi-Garage & Auto Care Assistant

Офлайн-додаток для обліку авто: гараж, ТО, нагадування, пальне,
дрібні витрати, аналітика. SQLite3, Kivy/KivyMD, оптимізовано під Pydroid 3.

## Встановлення в Pydroid 3

1. Відкрий Pydroid 3 → вбудований **Pip** → встанови по черзі:
   ```
   kivy
   kivymd
   pillow
   plyer
   ```
   `pytesseract` можна поставити, але сам розпізнавач `tesseract`
   Pydroid 3 не встановлює — без нього OCR-кнопки просто відкриють
   вибір фото і попросять заповнити поля вручну (додаток не впаде).

2. Розпакуй цю папку як є (структура нижче) у сховище телефону,
   відкрий `main.py` у Pydroid 3 і натисни ▶️ Run.

## Структура проєкту

```
garage_app/
├── main.py            # запуск, ScreenManager, тема
├── database.py         # SQLite-схема, CRUD, синхронізація пробігу
├── ocr_engine.py        # обробка фото + витяг дати/суми/пробігу/артикула
├── theme.py             # кольори матової графітової теми
├── screens/
│   ├── dashboard.py      # головний екран, каруселька авто
│   ├── car_card.py       # картка одного авто (для каруселі)
│   ├── car_menu.py       # 6 плиток модулів
│   ├── garage.py         # паспорт авто + історія модифікацій
│   ├── maintenance.py    # журнал ТО
│   ├── reminders.py      # нагадування/інтервали
│   ├── fuel.py           # заправки, витрата л/100км
│   ├── expenses.py       # дрібні витрати
│   ├── analytics.py      # місячна аналітика, грн/км
│   ├── settings.py       # мова/одиниці/валюта/бекап
│   ├── add_car.py        # форма додавання авто
│   └── common.py         # спільна кнопка "Камера/Фото" + OCR
├── assets/
│   ├── default_car.png
│   └── receipts/         # сюди копіюються фото чеків
└── garage.db             # створюється автоматично при першому запуску
```

## Що вже працює

- Повна SQLite-схема з єдиним джерелом істини для пробігу
  (`database.update_odometer` перераховує всі нагадування одразу).
- Каруселька авто зі свайпом, індикатором оливи (зелений/жовтий/червоний),
  стрічкою нагадувань.
- Journal ТО з деталями/цінами, нагадування з ручним і дефолтним інтервалом,
  пальне з автоматичним розрахунком витрати, дрібні витрати, аналітика
  по місяцях з грн/км.
- Кнопка "Камера/Фото" на кожній формі: копіює фото в `assets/receipts/`
  і намагається витягнути дату/суму/пробіг/артикул через OCR.
- Бекап/відновлення бази одним натисканням у Налаштуваннях.

## Збірка справжнього APK (через GitHub Actions)

Buildozer (інструмент, який пакує Kivy-проєкт в APK) тягне за собою
Android SDK/NDK і компілятори — це неможливо зібрати прямо в Pydroid 3
на телефоні. Натомість це робиться безкоштовно в хмарі через GitHub:

1. Створи новий репозиторій на https://github.com/new (наприклад
   `multigarage-app`), публічний або приватний — не важливо.
2. Залий у нього весь вміст цієї папки `garage_app/` (можна прямо
   через веб-інтерфейс GitHub: "Add file → Upload files", перетягнути
   всі файли й папки, і натиснути "Commit changes").
   Файли `.github/workflows/build-apk.yml` та `buildozer.spec` мають
   лежати в корені репозиторію — це вже так у цьому архіві.
3. Відкрий вкладку **Actions** у репозиторії — збірка "Build Android
   APK" запуститься автоматично після заливання коду.
   Перша збірка триває приблизно 15-25 хвилин (качає Android SDK/NDK).
4. Коли збірка позеленіє (✅), відкрий її та внизу сторінки в розділі
   **Artifacts** завантаж `multigarage-apk` — це готовий `.apk`.
5. Перекинь `.apk` на телефон (через Google Диск, USB, Telegram
   "Saved Messages" тощо) і встанови — Android попросить дозволити
   встановлення з "невідомих джерел", це нормально для APK поза Google Play.

Якщо збірка впаде з помилкою — відкрий лог кроку "Build APK with
Buildozer" в Actions, скопіюй текст помилки і надішли мені, я поправлю
`buildozer.spec` або код під конкретну причину.

## Обмеження на Pydroid 3 (чесно, без прикрас)

- **OCR** реально розпізнає текст лише якщо на пристрої є нативний
  `tesseract`-бінарник — сам Pydroid 3 його не постачає. Без нього
  кнопка камери просто дає вибрати фото і зберегти його як чек;
  поля заповнюються вручну.
- **Системні push-нагадування** (щоб спрацьовували, коли додаток
  закритий) вимагають Android-специфічного планувальника
  (AlarmManager/WorkManager), якого немає в межах Python-скрипта
  в Pydroid 3. Зараз перевірка "чи час на ТО" відбувається при
  запуску додатку через `plyer.notification` (локальне спливаюче
  повідомлення), без гарантії в фоні.
- Довгий тап для зміни фото авто відкриває вбудований файловий
  менеджер KivyMD — реальної камери там немає (Pydroid 3 не дає
  прямого доступу до Camera API), тож це вибір із галереї.
